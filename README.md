# easy-exam-skill

## 我的灵感

我认为通过性考试有技巧和快捷路径（与其相信整天忽悠你报班的营销号我更愿意相信能帮人类攻克数学难题的AI）：目标不是学完所有资料，而是在有限时间内优先掌握高价值考点，用真实测试不断确认自己是否已经具备通过能力。

这个想法来自 ChatGPT 会话：[题库答案分布分析](chatgpt-conversation://6a704540-739c-83e8-b965-863e4b80c40b)。

## 实现思路

`easy-exam-skill` 把考试日期、科目、合格线和学习时间写入配置，再按照“学习 → 盲测 → 锁定首次成绩 → 纠正错题 → 陌生题复测”的闭环推进备考。

它重点保护首次成绩，避免把看过答案后的正确误认为真正掌握；最后再用此前封存的整套试卷检验实际通过风险。

## 使用方式

先在考试项目中准备 `.easy-exam/profile.yaml`，填写考试信息和学习计划，然后调用：

```text
使用 $easy-exam-skill 根据我的考试配置安排今天的备考任务。
```

## 每日复习流程

```text
收到每日推送 → 复习学习包 → 完成盲测 → 锁定首次成绩并订正
             → 生成必要闪卡 → 通过 Computer Use 导入 Anki 并核对
```

闪卡只在盲测提交和批改后生成，主要覆盖错题、易混点和不稳定知识点，不把当天全部内容机械制卡。

## 当前状态：有待验证

这个每日推送复习任务的自动化流程是我为了复习中级注安师而设置的，是否能无痛通过考试还有待验证 。它现在只是一个基于个人思考和备考实践设计的实验性方案，不能视为经过验证的方法，也不保证使用后一定能够通过考试。

## 安装后的适配

安装 Skill 只能获得通用备考流程，首次使用前还需要在考试项目根目录创建 `.easy-exam/profile.yaml`，写入自己的考试配置。

必须修改：

- 考试名称、日期和时区；
- 科目、满分、合格线，以及是否要求逐科通过；
- 单选、多选、判断、案例等题型和计分规则；
- 工作日、周末可用时间和各阶段安排；
- 教材、题库、真题等资料目录；
- 法规、标准等内容的有效日期和来源优先级；
- 进度状态文件与每日学习包的输出目录。

新项目建议使用结构化状态文件：

```yaml
state:
  mode: structured
  path: .easy-exam/state.json

outputs:
  root: 每日学习
```

已有项目也可以使用 `legacy_markdown` 模式迁移原有进度记录。

可选适配：

- 每日推送：另外创建定时自动化，设置执行时间和时区，并让它调用 `$easy-exam-skill`；
- Anki 闪卡：本仓库不包含当前注安师项目使用的专用闪卡适配器。可以关闭闪卡流程，或创建适合自己考试的闪卡 Skill，并配置牌组、字段和 Computer Use 导入方式。

不要直接照搬当前项目中的四科结构、75 分训练目标、每日题量、封存真题年份和学习时长，这些都是中级注安师的个人配置，应根据自己的考试修改。

首次配置时可以直接对 Codex 说：

```text
使用 $easy-exam-skill，根据我的考试日期、科目、合格线、题型、
可用时间和资料目录，为当前项目创建 .easy-exam/profile.yaml。
```
